# Japanese Word App（日语单词记忆 App）

面向 JLPT 学习者的日语背词应用，基于间隔重复机制，解决传统卡片复习链路与手写记忆习惯不匹配的问题。

## 项目背景
- 目标用户：习惯手写背词、处于 JLPT N5 阶段的学习者
- 痛点：现有背词工具的复习节奏绑定卡片流程，手写动作无法接入复习计划，中断后难以回到原位

## 产品方案
- 悬浮球入口，轻量接入原有手写流程，不接管笔迹
- 第 1/2/4/7/15 天多周期复习，中→日、日→中、听力三部分主动回忆
- 错词独立回抄队列，支持同日 / 跨日进度恢复
